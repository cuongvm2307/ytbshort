YTBShort Privacy Policy

Last updated: November 19, 2026

YTBShort is a private tool, run on its operator's own computer, that uploads and schedules YouTube Shorts on the operator's own YouTube channels. This policy explains what data it accesses through Google and YouTube APIs and how that data is handled.

1. Data we access

When the operator signs in with Google, YTBShort requests these OAuth scopes:

  • https://www.googleapis.com/auth/youtube.upload to upload videos to the signed-in channel.
  • https://www.googleapis.com/auth/youtube.readonly to read the signed-in channel's ID and title, and the status of videos that YTBShort uploaded.

YTBShort also reads public metadata of public YouTube videos (titles, view counts, durations) to learn which topics are popular. It does not download other creators' videos unless the video carries a Creative Commons license, and it does not collect personal information about other YouTube users.

2. How the data is used

The data is used only to provide YTBShort's features to the operator: to upload the operator's videos, schedule them, and confirm they were published. It is not used for advertising, it is not sold, and it is not used to build user profiles.

3. Storage and security

All data stays on the operator's computer. OAuth refresh tokens are encrypted with AES-256-GCM using a key that never leaves that computer. Channel IDs, video IDs, titles and schedule times are stored in a local SQLite database. YTBShort has no server and does not send this data to any third party. The only exceptions are calls to Google services (YouTube Data API, and Gemini to draft titles and descriptions for the operator's own videos).

4. Sharing

We do not share, sell or transfer Google user data to anyone. YTBShort's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

Data is kept only as long as the operator uses YTBShort. Deleting the YTBShort folder removes all locally stored data and tokens. You can revoke YTBShort's access to your Google account at any time at https://myaccount.google.com/permissions. Google's handling of your data is described in the Google Privacy Policy.

6. YouTube Terms

YTBShort uses YouTube API Services. By using YTBShort you agree to be bound by the YouTube Terms of Service.
